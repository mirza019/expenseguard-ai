THE COMPLETE APPLICATION

Clone. Start. Audit.

The local Streamlit application includes CSV/XLSX uploads, four analytical tools, interactive charts, and a bounded LangGraph + ChatOllama agent.

git clone https://github.com/mirza019/expenseguard-ai.git
cd expenseguard-ai
./start.sh

Requires Python 3.11 or 3.12. Before the implementation PR is merged, check out docs/project-documentation. Install Ollama separately, then choose Download & Enable AI inside the app. Deterministic audits work without it.
