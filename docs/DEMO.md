# Fictional product demonstration

All demonstration data is synthetic.

1. Start the application with `./start.sh`.
2. Open **Data & Context** and select **Try fictional sample**.
3. Inspect validation, source preservation, and the draft Budget Variance definition.
4. Approve the definition only if its formula and scope are acceptable.
5. Open **Agent Workflows** and run **Monthly financial review** for the latest period.
6. Review actual, represented budget, variance, material departments, observed contributors,
   execution trace, and limitations.
7. Run the secondary expense compliance audit.
8. Optionally load the fictional policy corpus and repeat the audit with cited policy evidence.
9. Open **Reports & Governance** to inspect findings and create a reviewable PDF.

Expected behavior: unknown budgets remain unknown, contributors are not presented as confirmed
causes, optional AI never recalculates financial totals, and reports remain drafts for human review.
